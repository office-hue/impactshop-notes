## 🎯 Célközönség

Ezek az útmutatók **civil szervezeteknek** készültek, akik:
- Szeretnék megérteni, hogyan működik a Sharity
- Be akarják ágyazni a widgeteket a saját oldalukra
- Kommunikálni szeretnék a támogatóiknak a lehetőséget
