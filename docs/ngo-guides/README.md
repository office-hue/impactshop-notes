# NGO Útmutatók – Sharity Platform

Ez a mappa tartalmazza az NGO-k számára készült tájékoztató dokumentumokat a Sharity platform funkcióiról.

## 📁 Tartalom

| Dokumentum | Leírás |
|------------|--------|
| [Impact Activity útmutató](./impact-activity-guide.md) | Videónézésből adomány – szavazatok, rangsor, adományalap |
| [Impact Shop útmutató](./impact-shop-guide.md) | Vásárlásból adomány – affiliate rendszer, webshopok |
| [NGO Card útmutató](./ngo-card-guide.md) | Beágyazható widget – élő adomány kijelzés |

## 🎯 Célközönség

Ezek az útmutatók **civil szervezeteknek** készültek, akik:
- Szeretnék megérteni, hogyan működik a Sharity
- Be akarják ágyazni a widgeteket a saját oldalukra
- Kommunikálni szeretnék a támogatóiknak a lehetőséget

## 📖 Használat

A dokumentumok Markdown formátumban vannak, de könnyen konvertálhatók:
- Weboldalra (HTML)
- PDF-be
- WordPress oldalra
