# 327. Beszélgetés összefoglaló: PIN REST payload minták + hibakód mátrix

Kérés: a PIN visszaállításhoz tartozó REST payload minták és hibakód mátrix
megírása.

- Dokumentáció bővítve: `impact-hub-system-v1.3.md` 4.1 fejezet.
- `pin/issue` és `pin/verify` JSON kérés/válasz minták.
- Hibakód táblázat: `invalid_request`, `pin_invalid`, `pin_locked`, `pin_expired`,
  `pin_used`, `rate_limited`, `server_error`.
