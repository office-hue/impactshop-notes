> 🆕 Autó generált Drive index: futtasd a `npm run drive:catalog` parancsot, amely frissíti a `drive-katalogus.md` fájlt (teljes fájllista, méret, módosítás, kulcsszavak) és a `tools/out/drive-catalog.json` struktúrát az AI kereséshez.

## Használati javaslat
- **Keresés**: használd a kulcsszavakat (pl. „adatkezelés” → tájékoztató + szabályzat).
- **Értelmezés**: a leírás alapján válaszd ki a kérdéshez illő forrást (pl. Impact Challenge → `Impact Challenge leírás.pdf`).
- **Frissítés**: új dokumentum esetén add hozzá a táblázathoz a fájlt, részletes leírást és kulcsszavakat; a pénzügyi/Excel állományoknál csak a lexikai tudást sorold ide.
