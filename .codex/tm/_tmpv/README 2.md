# ImpactShop – Projekt Napló

Cél: ImpactShop/WordPress integráció, akciós termékek linkjeinek javítása, karbantartása, affiliate hijacking védelem.

## Legújabb fejlesztések
- **13. beszélgetés (2025-09-21)**: Affiliate hijacking detektálás és védelem Dognet Publisher API integrációval
- **Anti-hijack védelem**: JavaScript alapú real-time link monitoring és CHID paraméter ellenőrzés
- **Timezone-aware ellenőrzés**: Dognet időzóna (Europe/Bratislava) szerinti kattintás verifikáció  
- **Ping diagnosztika**: Redirect lánc végigkövetése WAF/AdBlock detektáláshoz

Hasznos mappák:
- `notes.md`: döntésnapló, teendők
- `snippets/`: fontos kódrészletek külön fájlban
- `conversation-summaries/`: ChatGPT beszélgetések összefoglalói
- `chatgpt-history/`: teljes beszélgetés archívum
